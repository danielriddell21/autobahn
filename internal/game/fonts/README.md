# Fonts

Overpass, regular, bold and extra bold, used for the menus.

Copyright 2021 The Overpass Project Authors (https://github.com/RedHatOfficial/Overpass).
Licensed under the SIL Open Font License, Version 1.1; the licence is in `OFL.txt`.

The files are the TrueType files from the `@expo-google-fonts/overpass` npm
package (version 0.4.2), unmodified. They are embedded with `go:embed` and
loaded with `rl.LoadFontFromMemory`.
